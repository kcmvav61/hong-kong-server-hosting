## 哪些人不需要這些方案

**只需要放一台低流量自有伺服器的人**，直接找 1U 或 2U 託管就好，月費幾百港元，不必買 VPS 或獨立伺服器。你已經有硬件，再租一台虛擬機是重複支出。

**完全不想碰系統和硬件的人**，要的是連管理一併外包的專屬伺服器，而不是自己裝作業系統、自己打補丁的裸機。這類供應商通常在方案裡包含監察、硬件替換和技術支援熱線，月費自然較高。

**開 Minecraft 或 Steam 遊戲服的人**，用遊戲主機面板比租獨立伺服器省事。一鍵部署、隱藏源 IP、DDoS 緩解這些功能，自己裝要花不少時間，而且入門價只要幾十港元。

**需要 GPU、大容量 SAS 陣列或特殊硬件的人**，要買的是自定義配置，標準套餐表幫不上忙。下單前先向客服確認供貨和交期，這類配置的交付時間可能是數個星期，不是數個工作天。

## 常見問題

**香港伺服器租用一個月多少錢？**
按類型分：機櫃託管 1U 約 HKD750–900/月，入門 VPS 約 US$5/月，獨立伺服器由 US$130/月起，遊戲主機由 HKD30/月起。三者的口徑不同，不能直接比較。

**要不要簽長約？**
視供應商而定。有託管商寫明 20U 以下免簽約，有專屬伺服器商只接受半年或年付。簽之前確認最短租期和提前終止條款。

**幾耐開通？**
小額託管方案可以即日開通，較大的機櫃位需 2–3 個工作天；標準獨立伺服器通常數個工作天，特殊硬件由一星期至數星期；VPS 一般在下單後短時間內交付。

**包幾個 IP？**
入門方案通常 1 個 IPv4。額外 IP 按月收費，本地託管商定價 HKD150/月，另一間專屬伺服器商定價 HKD200/月。

**可不可以挖礦？**
部分本地託管商明文禁止任何形式的採礦機，一經發現即時終止並追收行政費。租用前先確認條款。

**帶寬是獨享還是共享？**
要逐項確認。託管方案多數寫「機櫃共享商業寬頻」，獨立伺服器常見「100MB 香港共享、2MB 國際共享」，VPS 的端口速率也是共用上行。真正獨享頻寬要另外申請，月費另計。

**可不可以退款？**
沒有統一標準。有遊戲主機商承諾三天內全額退款，有供應商按合約處理。下單前在結賬頁看清退款條款。
